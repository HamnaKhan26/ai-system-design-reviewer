# 🧠 AI System Design Reviewer

An **AI-powered System Design Reviewer** that analyzes high-level architecture descriptions and provides **multi-dimensional feedback** (Scalability, Reliability, Security, Cost, Tradeoffs) along with a **simplified architecture diagram (Mermaid)**.

---

## 🚀 Features

- 🧩 **Multi-Reviewer AI Analysis**
  - Scalability
  - Reliability
  - Security
  - Cost Optimization
  - Architectural Tradeoffs

- 📊 **Auto-Generated Architecture Diagram**
  - Outputs a simplified Mermaid diagram
  - Frontend renders architecture visually

- ⚡ **Local LLM Execution**
  - Runs fully locally using **Ollama**
  - No OpenAI / external API dependency

- 🧠 **Model-Agnostic**
  - Supports `mistral:latest`, `llama`, or any Ollama model

- 🛠️ **Full-Stack Implementation**
  - Backend: Node.js + Express + TypeScript
  - Frontend: React + Mermaid
